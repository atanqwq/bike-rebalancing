# 数据特征字典 (Feature Dictionary)

本文件定义了 `clean.csv` 中包含的所有字段，供模型训练和后续分析使用。当前实际输出为 22 列。

## 字段说明表

| 字段 | 含义 | 类型/范围 | 来源或处理方式 |
| :--- | :--- | :--- | :--- |
| `datetime` | 小时时间戳 | datetime | 由原始日期和小时拼接 |
| `station_id` | 站点编号 | 0-N-1 | 站点化后生成 |
| `hour` | 小时 | 0-23 | 时间特征 |
| `dow` | 星期 | 0-6 | 时间特征 |
| `is_weekend` | 是否周末 | 0/1 | 星期派生 |
| `season` | 季节 | 1-4 | 原始数据 |
| `weather` | 天气等级 | 1-4 | 原始数据 |
| `temp`、`hum`、`windspeed` | 气象特征 | 原始单位 | 原始数据 |
| `is_rush` | 是否早晚高峰 | 0/1 | 由小时派生 |
| `lag_1`、`lag_24` | 前1小时、前24小时需求 | 数值 | 站点内 shift |
| `roll_24` | 24小时滚动均值 | 数值 | 站点内滚动 |
| `demand` | 需求 | 非负数值 | 清洗后的目标 |
| `demand_level` | 需求等级 | low/mid/high | 分位数离散化 |
| `temp_n` | 归一化温度 | [0, 1] | Min-Max 归一化 |
| `hum_n` | 归一化湿度 | [0, 1] | Min-Max 归一化 |
| `windspeed_n` | 归一化风速 | [0, 1] | Min-Max 归一化 |
| `lag_1_n`、`lag_24_n` | 归一化滞后特征 | [0, 1] | Min-Max 归一化 |
| `roll_24_n` | 归一化滚动均值 | [0, 1] | Min-Max 归一化 |

## 同时说明：

1. **滞后特征**（`lag_1`、`lag_24`、`roll_24`）按 `station_id` 分组计算，**绝对没有跨站点串行**，保证了时间序列的独立性。
2. **归一化**不覆盖原始列，只是新增了带 `_n` 后缀的列。
3. 离散化（`demand_level`）的分位点，是严格按 `demand` 的三分位数（33.3% 和 66.6%）计算的。
4. 当前数据共有 40 个站点，站点的坐标来源于**规则网格加轻微扰动**（并非真实物理坐标）。
